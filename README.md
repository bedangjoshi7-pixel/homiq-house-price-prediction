# HomIQ

House price prediction using Linear Regression from scratch, NumPy, and Streamlit.

## Features
- Predict house prices based on house size.
- Linear Regression implemented from scratch.
- Gradient descent and cost function.
- Interactive Streamlit interface.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Streamlit

## Run Locally
```bash
pip install numpy pandas matplotlib streamlit
streamlit run PredictionGUI.py
```

## Purpose
A learning project built to understand the fundamentals of Machine Learning.

#Note
You may change the training data for the model.The output of the model will be affected according to the dataset used.
